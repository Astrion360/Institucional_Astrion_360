# Astrion Assessoria — Apresentação Institucional HTML

## Arquivos
- `index.html` — apresentação completa.
- `styles.css` — identidade visual, responsividade, animações e regras de impressão.
- `assets/` — logo e fotos institucionais utilizadas no material.

## Como abrir
1. Mantenha `index.html`, `styles.css` e a pasta `assets` juntos.
2. Abra `index.html` em Chrome, Edge, Safari ou Firefox.
3. A navegação superior leva às principais seções. A página também funciona como deck vertical.

## Como exportar para PDF
Recomendado: Chrome/Edge.
1. Abra `index.html`.
2. Pressione `Ctrl+P` / `Cmd+P`.
3. Destino: **Salvar como PDF**.
4. Layout: **Paisagem**.
5. Margens: **Nenhuma**.
6. Escala: **100%**.
7. Marque **Gráficos de fundo**.
8. O CSS de impressão já configura cada seção como uma página 16:9.

## Uso executivo
- Para reunião C-Level, use em tela cheia no navegador e navegue por scroll ou pelos links do topo.
- Para envio prévio ou posterior à reunião, prefira PDF.
- Para um case específico, duplique o HTML e adapte somente as seções de investimento, referências e governança.
